How this works

No HTML or template syntax to learn — everything here is branding. The document itself (document number, transaction details, the line-item table, notes, and signature lines) is always laid out automatically and filled in with the real transaction's data every time a PDF is generated; you can't break that layout from this screen.

What you control:

  • Logo — shown at the top of every generated PDF.
  • Logo position — left, center, or right of the title.
  • Accent color — used for the title and the rule under the header.
  • Font — applied to the whole document.
  • Page margins — how much blank space surrounds the page content.
  • Page size / orientation — A4 or Letter, portrait or landscape.
  • Page numbers / signature block — toggle either on or off.
  • Header / footer text — a short line repeated on every page.
  • Standing notes / terms — fixed text shown on every document, separate from that delivery's own notes.
  • Hidden columns — remove line-item columns you never need (e.g. SKU).

Save validates the result by rendering a real sample PDF first — a problem would be reported here, never discovered the next time someone prints a real document. Use the live preview as often as you like before saving.
